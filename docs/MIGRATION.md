# 기존 v10 데이터 옮기기

## 권장 방법: JSON 백업

1. 기존 로컬 v10을 연다.
2. `설정 / 백업`에서 `백업 다운로드`를 눌러 JSON 파일을 저장한다.
3. 배포된 클라우드 앱에 Google 로그인한다.
4. `설정 / 백업`에서 `백업 불러오기`로 JSON을 선택한다.
5. 같은 ID는 갱신하고 새 항목은 추가하는 방식으로 Firestore에 병합된다.

기존 로컬 HTML을 `file://`로 열어 사용한 경우, 브라우저 보안상 GitHub Pages 주소에서 그 IndexedDB를 직접 읽을 수 없다. 그래서 JSON 백업 경로가 가장 확실하다. 동일 웹 주소에서 구버전을 썼던 경우에는 첫 로그인 시 그 주소의 IndexedDB를 감지해 자동 이전 선택지를 보여준다.

기존 백업에 base64 사진이 있으면 가져오기 과정에서 `drive.file` 권한으로 앱이 만든 전용 Google Drive 폴더에 업로드한다. 앱은 Drive 전체 파일을 읽을 수 없고, 이 앱이 만들거나 사용자가 이 앱으로 연 파일만 다룬다.
