# 배포 검증 체크리스트

- [ ] PC 세션 A에서 만든 업무가 세션 B에 나타난다.
- [ ] 상태 변경이 다른 세션에 실시간으로 반영된다.
- [ ] 체크리스트 체크/해제가 다른 세션에 반영된다.
- [ ] 1단계 시작일 변경 시 기존 2·3·4단계 일정이 재계산된다.
- [ ] 같은 `generatedKey`의 자동업무가 한 건만 존재한다.
- [ ] 변경 직후 간트와 달력에 같은 날짜가 표시된다.
- [ ] 새로고침 뒤에도 업무·체크·완료 이력이 유지된다.
- [ ] 로그아웃 상태의 Firestore 읽기/쓰기가 `permission-denied`로 거부된다.
- [ ] 360px 모바일, 태블릿, 1280px 이상 PC에서 가로 잘림 없이 핵심 조작이 가능하다.
- [ ] Android/갤럭시탭/iPad에서 홈 화면 설치 후 standalone으로 열린다.
