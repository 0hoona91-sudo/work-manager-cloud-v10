# 배포 검증 체크리스트

2026-09-05 기준. `자동 통과`는 저장소의 실제 최종 함수 또는 배포 파일을 대상으로 한 회귀 테스트이며, `실기기 대기`는 Firebase 소유자 UID 확정·규칙 게시 뒤 두 브라우저/실기기에서 마쳐야 하는 항목이다.

| 검증 항목 | 상태 | 현재 근거 |
| --- | --- | --- |
| PC 세션 A에서 만든 업무가 세션 B에 나타난다 | 실기기 대기 | 소유자 UID가 들어간 최종 Rules 게시 후 실행 |
| 상태 변경이 다른 세션에 실시간 반영된다 | 실기기 대기 | 컬렉션별 `onSnapshot` 구현·계약 테스트 통과 |
| 체크리스트 체크/해제가 다른 세션에 반영된다 | 실기기 대기 | 체크항목 독립 문서 및 문서 단위 diff 테스트 통과 |
| 1단계 시작일 변경 시 기존 2·3·4단계 일정이 재계산된다 | 자동 통과 | 2026-09-04→09-08 이동 후 2·3·4단계가 09-09, 09-11, 09-14로 재계산됨 |
| 날짜 변경으로 같은 업무가 중복 생성되지 않는다 | 자동 통과 | 기존 네 개 ID와 건수가 재계산 전후 동일 |
| 같은 `generatedKey`의 자동업무가 한 건만 존재한다 | 자동 통과 | 같은 범위 두 번 동기화 시 두 번째 생성 0건, 완료 이력 우선 중복 복구 통과 |
| 변경 직후 간트와 달력이 함께 갱신된다 | 자동 통과 / 화면 확인 대기 | 날짜 변경 경로의 목록·HOME 재렌더와 간트·달력 동시 렌더 계약 통과 |
| 새로고침 뒤 업무·체크·완료 이력이 유지된다 | 실기기 대기 | Firestore 영속 캐시·IndexedDB 저장 구현, 로그인 뒤 최종 확인 필요 |
| 로그아웃 상태의 Firestore 읽기/쓰기가 차단된다 | 실제 통과 | 비인증 REST 읽기와 쓰기 모두 HTTP 403 `PERMISSION_DENIED` 확인 |
| PC 화면에서 핵심 UI가 열린다 | 실제 통과 | 배포 URL의 2026년 9월 HOME·간트·달력·내비게이션 렌더 확인 |
| 360px 모바일·태블릿·1280px PC에서 핵심 조작 가능 | 실기기 대기 | 반응형 규칙 존재, Cloud Browser 파일 선택창 장애로 최종 화면 회귀 미완료 |
| Android·갤럭시탭·iPad에서 홈 화면 설치 후 standalone 실행 | 실기기 대기 | manifest `standalone`, 192/512 아이콘, 서비스 워커·Firebase 모듈 사전 캐시 계약 통과 |
| Google Drive 사진 업로드·다른 기기 열람 | 실기기 대기 | `drive.file` 최소 권한과 Drive 파일 ID 저장 구현, Drive API 승인 뒤 확인 필요 |
